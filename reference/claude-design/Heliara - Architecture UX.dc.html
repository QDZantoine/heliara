Pourquoi cet ordre
1. Affirmer avant de prouver. Le hero pose la promesse ; la preuve sociale la crédibilise 3 secondes plus tard, avant tout argument.
2. Quoi → comment → preuve. Expertises (ce qu'on fait) puis méthode (comment) puis réalisations et chiffres (la preuve). L'ordre naturel d'un entretien commercial.
3. Rythme binaire. Alternance section dense / section respirante (preuve sociale, chiffres, citation) pour limiter la charge cognitive.
4. La demande arrive après la confiance. Le CTA final n'apparaît qu'une fois les trois objections levées (compétence, méthode, résultats). Avant, il reste discret dans la nav.
